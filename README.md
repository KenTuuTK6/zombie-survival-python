# Zombie Survival 

A beginner Python text-based survival game I'm building while learning Python programming.

## Features
- Player stats: health, money, and ammo
- Multiple player objects
- Taking damage
- A shop with different products
- Buying items using player money

## What I'm learning
- Python classes and objects
- Attributes and methods
- If/elif/else conditions
- User input
- Basic game logic and debugging

## Planned features
- Healing and health items
- Weapon selection and inventory
- Zombies and combat
- More shop items and survival mechanics

## Status
Work in progress. This is one of my first Python projects, and I'm improving it as I learn.
